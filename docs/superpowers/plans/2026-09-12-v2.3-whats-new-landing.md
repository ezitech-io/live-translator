**Goal:** Update the landing page release marketing from v1.14.7 to v2.3 across `#whats-new`, the Features one-liner, and `changelog.html`.

**Architecture:** Static content-only edits. Keep the existing What’s New 2×2 card layout, badge, and `glass-card` chrome. Swap version strings, blurb, four card bodies (and icons for meaning), the Features “New in…” line, and prepend a changelog block. No JS, CSS, or layout changes.

**Tech Stack:** Static HTML5, Tailwind via CDN (unchanged), existing Heroicons-style inline SVGs.

## Global Constraints

- **Repository:** `live-translator-landing` at `E:\ezitech\live-translator-landing`.
- **Files touched:** `index.html`, `changelog.html` only. Do not modify `desktop/`, instruction pages, or pricing markup.
- **Version string shown to users is exactly:** `v2.3` (not `v2.3.0`).
- **Changelog date is exactly:** `September 12, 2026`.
- **Copy must match the approved spec verbatim** for headlines, blurbs, card titles/bodies, Features one-liner, and changelog bullets.
- **Keep older changelog entries** — prepend only; never rewrite v1.14.7 or earlier.
- **Line numbers refer to the file before Task 1.** Locate edits by quoted snippets, not line numbers alone.
- **Commits:** only when the user explicitly asks (repo user rule). Plan steps still note `git add` / suggested messages for when they do.
